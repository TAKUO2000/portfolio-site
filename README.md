# 個人ブログサイト
## 概要
TAKUO2000の日々の技術的な学びや趣味の内容などをまとめた個人ブログサイト
laravel,Nextjs,AWSの技術習得用に開発

## 主な機能
 - TAKUO2000（管理者）による記事CRUD機能
 - 閲覧ユーザー用登録機能
 - 管理者、閲覧ユーザー用認証機能
 - コメント、リアクション機能
 - カテゴリ・タグ検索機能

## 技術スタック
backend:PHP(Laravel)
frontend:TypeScript(Nextjs)
infra:Terraform,AWS(S3（state用）,S3(記事画像用),EC2,Route53,Amplyfy),GitHubActions
